Settings

Where these keys live. Everything on this page is stored in this browser only, under this site's own origin. Nothing is uploaded, nothing is committed to the repository, and no server here can read it. That also means it is only as private as the device you are sitting at — and a key kept in a browser can be read by anything that can run script on this page.

For a bot that trades unattended, do not put trading keys here. The bot reads its own credentials from a .env file on the machine it runs on, which is gitignored and never reaches this page. Use this page for read-only keys and for the assistant keys below.

Dashboard data

Where the dashboard reads the bot's published JSON from. Leave as ./data for files published alongside this page, or point it at a server that serves them.

Assistants

Used by the dashboard's explain-this feature only. The trading logic does not call a model to decide anything — a language model cannot be backtested, and a decision that cannot be measured has no place in the risk path.

Brokers & exchanges

Read-only keys are enough for the dashboard. Never enable withdrawals on a key you paste anywhere.
Paper keys start with PK; live keys with AK. The bot refuses to place live orders unless it is explicitly configured for them.

News & data

The bot's own news comes from public RSS and needs no key. These are for optional richer sources.

Running it unattended

This page is static — GitHub Pages serves files and cannot run the bot. To trade around the clock, the bot runs on a machine you control and publishes its results here. deploy/README.md in the repository has a systemd unit and a docker-compose file that do exactly that: run the daily cycle, publish the JSON, push it. The Export .env button above writes the keys from this page into the format that machine expects.
